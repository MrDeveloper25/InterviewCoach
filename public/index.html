Dos números que suman el objetivo

Dado un arreglo de enteros y un objetivo, devuelve los índices de los dos números que suman el objetivo.

def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i

Tiempo O(n), espacio O(n). Así se ve la retroalimentación al terminar.
