# Flujo de trabajo

1. Toma una tarea del [tablero](https://github.com/users/MrDeveloper25/projects/12) y asígnatela.
2. Crea una rama desde `main` por tarea: `feature/nombre-corto` o `fix/nombre-corto`.
3. Haz commits pequeños y ejecuta `npm test` antes de subirlos.
4. Abre un pull request hacia `main` que incluya `Closes #número`.
5. Un compañero revisa y aprueba antes de fusionar.

`main` debe protegerse en GitHub (**Settings → Branches**): pull request obligatorio con al menos una aprobación.
